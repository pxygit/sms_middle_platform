# smspool Adapter

The MVP adapter is based on `smspool_postman.json`.

Implemented endpoints:

- `POST /request/balance`
- `POST /purchase/sms`
- `POST /sms/check`
- `POST /sms/cancel`

Planned informational endpoints:

- `GET /country/retrieve_all`
- `GET /service/retrieve_all`
- `POST /request/price`
- `POST /sms/stock`
